Doclick local launcher

Place START_DOCLOCK.bat and RESET_TOKEN.bat in the same folder as:
- index.html
- server.js

Start:
1. Double-click START_DOCLOCK.bat
2. Paste JOB_ADMIN_TOKEN when asked
3. Keep the black window open
4. Use http://127.0.0.1:8765/index.html

Reset token:
Double-click RESET_TOKEN.bat, then run START_DOCLOCK.bat again.

Do not open index.html directly by double-clicking it.
